# Code and data availability

Analysis scripts, pinned dependencies, reproducibility instructions and aggregate numerical outputs are available at:

https://github.com/sifat371/PD-gait-weargaitpd

The source WearGait-PD dataset is available through Synapse, accession syn52540892 (https://doi.org/10.7303/syn52540892), subject to its access terms. The repository does not redistribute the underlying clinical or gait CSVs or individual participant-level results.

Manuscript-reported summary tables are provided in `results/manuscript/` and code-generated aggregate model outputs in `results/analysis_outputs/`.
